## 0 执行方式与环境

```powershell
chcp 65001
$env:LC_ALL = 'C'
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -d yunqi_hotel `
    -v ON_ERROR_STOP=1 -P pager=off -f "sql/04_queries.sql" -o "work/04_queries_out.txt"
```

- `-P pager=off`：否则终端停在 `-- More --`。
- `$env:LC_ALL='C'`：把 psql 自身的提示语（`(34 行记录)`）切成 `(34 rows)`，否则这行以 GBK 字节混入 UTF-8 输出文件。
- **已知 Windows 终端问题**：psql 会把查询**数据**按控制台码页转换输出，但服务端**消息**（`NOTICE`/`ERROR`）按客户端编码原样输出，中文在 cp936 终端必乱码；psql 自带的中文消息前缀（`注意:`）改环境变量无效。→ 脚本里的 `RAISE NOTICE` 一律写 ASCII；看中文结果用 `Get-Content work/04_queries_out.txt -Encoding UTF8` 或直接用编辑器打开。
- 结论：乱码只影响终端显示，**不影响入库数据，也不影响 `-o` 落盘文件**（该文件已用 Python 严格 UTF-8 解码验证通过）。
