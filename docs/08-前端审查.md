## 7 二轮修订（2026-10-31 晚，按用户反馈）

用户反馈四条：① 界面一片白、单调；② 侧栏悬停时文字变白不可见；③ 登录页没变化；④ 没有动效，
原来的看板剪影像有动效。逐条处理：

| 反馈 | 原因 | 处理 |
| --- | --- | --- |
| 一片白 | 一轮把「去饱和」做过头：地面、顶栏、侧栏、卡片全接近 `#fff`，没有分区层次 | 顶栏改为墨色 `#123642`（与登录页同族）；地面 `#eaeff1`、侧栏 `#f2f5f6`、卡片表头 `#f4f7f8`、表头 `#eef3f4`，形成「墨顶 / 浅侧 / 灰地 / 白卡」四层；页头标题前加 3px 金色短竖条 |
| 悬停白字 | AdminLTE 的 `sidebar-dark-primary` 用 `nav-link:hover{color:#fff}`，我的浅色化规则没压住（选择器权重够但缺 `.sidebar-dark-primary` 前缀与 `p` 子元素） | 新增 `.sidebar-dark-primary .nav-sidebar > .nav-item > .nav-link:hover/:focus` 及其 `p`/`i` 规则并 `!important`；悬停底 `#dfe8ea`、激活行 `#d9e6ea` + 左侧 3px 主色内阴影 |
| 登录页没变 | 一轮只做了纯色底，视觉上确实接近原来；且浏览器缓存了旧 `site.css`（无指纹） | 墨底 + 两处极淡径向光（青 / 金）+ 卡片顶部金→青渐变线 + 卡片入场；同时给 `site.css`/`site.js` 加 `?v=20261031b` 指纹，避免演示机缓存 |
| 没动效 | 一轮只留了 border-color 过渡，还把 KPI 的 `icon` 整块 `display:none`，连带丢掉了模板原有的图标剪影 | 恢复 `small-box .icon`：52px 同色系淡水印，悬停 `translateY(-3px) scale(1.05)` + 加深；卡片与 KPI 悬停微浮；页头与各列 320ms 错峰入场；按钮按压 `scale(.985)`；全部在 `prefers-reduced-motion: no-preference` 内，减少动效时自动关闭 |

补充说明：KPI 剪影只做「淡水印」（10%–22% 不透明度）与状态色区分，不是原先那种饱和色块 + 2em 白图标，
色块与彩底仍然不复存在。

## 8 三轮修订（2026-10-31 晚，KPI 辨识度）

用户反馈：四张 KPI 剪影颜色太接近，有美感但没有辨识度（附房态看板四卡截图）。
根因：第二轮把剪影统一压成 10% 不透明度的同色系水印，四个状态只剩「深浅差」，
在 1440 宽下几乎同色。

处理（`site.css` v3 段落）：

| 手段 | 说明 |
| --- | --- |
| 3px 左侧状态色 | 每张卡内阴影 `inset 3px 0 0 var(--kpi)`，不占布局、不描边 |
| 标签前 6px 色点 | 与左侧色、剪影同色，扫一眼就能分「哪一类」 |
| 剪影按状态换色 | 18% → 24% 不透明度：正常 `#2f7d5d` 绿 / 清洁中 `#2f6f9f` 蓝 / 维修中 `#a9761c` 琥珀 / 停用 `#64748b` 石墨 |
| 悬停 | 剪影升到 55% 不透明度并回到状态主色 |
| 徽章同源 | `.badge-success/info/warning/danger/secondary` 统一为浅底深字，三处（KPI / 卡片 / 表格）同色 |

数字仍是墨色：颜色只承担「哪一类」的信息，不承担数值大小，避免四块彩色数字互相抢。

验证：离线冒烟 190/0（真库只读 131/131 未受 CSS 影响，仍以最近一次为准）；
截图 `work/shots/after/{room_board,reception_dashboard,manage_index}.png`。
