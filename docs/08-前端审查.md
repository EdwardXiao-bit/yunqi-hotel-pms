## 3 不改的部分（保持）

- 框架与资源：AdminLTE 3.2 / Bootstrap 4.6 / 本地 vendor，全部不动；表单 `name`、URL 名、CSRF、`data-confirm` 不动。
- 业务文本与断言口径：`可用房查询`、`应收合计`、`text-monospace` 等冒烟断言依赖的字样保留。
- 页面结构：区块顺序、栅格列宽、表格列数不动。
