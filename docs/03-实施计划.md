### 4.2 目录与脚本

```
src/                       Django 工程根（manage.py 所在）
├─ manage.py
├─ config/                 settings.py / urls.py / wsgi.py
├─ core/                   业务 app：models / views / forms / services / urls.py / admin.py
├─ templates/              base.html、partials/（head/sidebar/navbar/footer/scripts）、业务页、登录页
└─ static/
   ├─ vendor/adminlte/     AdminLTE 3.2 的 dist/ 与 plugins/
   ├─ css/site.css         中文排版与少量覆盖
   └─ js/site.js
sql/
├─ 00_database.sql      建库（幂等 CREATE DATABASE … \gexec）+ 时区/编码/datestyle
├─ 01_schema.sql        建表（含 PK/FK/NOT NULL/UNIQUE/CHECK）、索引、表与字段注释
├─ 02_constraints.sql   生成列 during、EXCLUDE 排他约束、部分唯一索引、视图、触发器、可用房函数
├─ 03_seed.sql          6 房型 / 40 房 / 7 客户 / 60 预订 / 30 入住 / 60 支付（含边界数据）
└─ 04_queries.sql       报告第 4 章 Q1–Q8 查询（可直接跑出结果）+ Q8 约束实测
```

- `00`–`04` 全部**可重复执行**（`DROP ... IF EXISTS` / `IF NOT EXISTS` / `\gexec` 幂等建库），每次改表结构都 01 → 02 连跑验证。
- `04_queries.sql` 里的每条 SQL 都要能贴进报告并附执行结果截图；实测结果见 `docs/05-查询结果与测试记录.md`。
- Django 侧的表结构以 `sql/01–02` 为准；`manage.py migrate` 只建 `auth` 等内置表，业务模型一律 `managed = False`（不重复写 DDL，也不再用 `migrations.RunSQL`），**以脚本为唯一事实来源**。

- `F03` 可用房查询、`F09` 入住率查询各跑一次 `EXPLAIN (ANALYZE, BUFFERS)`，确认走了索引，输出存档到 `work/`。**状态：未做**（依赖 Django 页面里的实际 SQL，随 T6/T12 一起补；纯 SQL 版可先用 `docs/05` 的 Q1/Q3 跑）。

## 6 风险与对策

| # | 风险 | 影响 | 对策 |
| --- | --- | --- | --- |
| R1 | `EXCLUDE` 约束漏写 `WHERE` 谓词，历史已退房记录被误判冲突 | 预订全部失败 | 约束必须带 `WHERE (status IN ('pending','confirmed','checked_in'))`；建库后用“已退房同房号同区间”用例回归 |
| R2 | 日期语义不统一（半开/闭区间混用） | 退房当天入住失败或超卖 | 全系统统一 `[check_in, check_out)`；后端封装 `daterange()` 工具函数，禁止散落字符串拼 SQL |
| R3 | 结算规则含糊（提前退房、超时退房） | 金额对不上，报告说不清 | 11/30 前把规则定成表格写进报告 3.2；提前退房按实际天数、超时按加收半天 |
| R4 | 演示数据与房态不一致 | 现场演示穿帮 | 数据只用 `03_seed.sql` 生成，禁止手工改库；每次改约束后重跑种子脚本 |
| R5 | 时间不足（考试周冲突） | 交付不完整 | 砍功能顺序：先砍 F01 区间价格（降为标准价）、再砍增值服务；F03–F07 与统计不可砍 |
| R6 | 本机环境问题（端口占用、口令错） | 现场演示失败 | 11/09 前每人本机跑通一遍；准备 `pg_dump` 备份与一键启动脚本；口令写 `.env` |
| R7 | Django ORM 让 SQL 隐身，报告 4 章没 SQL 可贴 | 数据库 50% 失分 | 约定复杂查询必须 `connection.cursor()` 手写；每个功能验收时检查“SQL 在哪” |
| R8 | AdminLTE 3.2 基于 Bootstrap 4（已停止维护），与网上的 BS5 教程对不上 | 改样式时踩坑 | 版本锁定 3.2 到 `static/vendor/`，只做少量覆盖，不升级、不追 BS5；布局问题查 [v3.2 官方文档](https://adminlte.io/docs/3.2/) 而不是 BS5 文档 |

- **页面/表单契约先行**：T4 完成当天把 9 个功能的 URL、模板名、表单字段写进 `docs/页面约定.md`；两人按模块拆页面（预订 / 前台 / 统计），不抢同一模板文件。
- **改动即落盘**：表结构变更同步更新 `02-数据库设计.md` 与 `AGENTS.md`（重跑 `psql -f` 验证）。
- **演示彩排不少于 2 次**，每次按 5 分钟动线计时（查询 → 预订 → 入住 → 退房 → 看板 → 统计）。
